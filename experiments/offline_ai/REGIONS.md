# 인구 특성 지역 군집화

## 현재 범위

Python 표준 라이브러리로 구현한 오프라인 K-means다. 추가 API, DB, Python 서버 및 런타임 패키지가 필요 없다. 운영 API와 연결하지 않았으며 실제 용인시 원본 파일 다운로드가 실패해 실제 데이터 학습도 아직 하지 않았다. 테스트의 synthetic 지역은 계산 검증용이며 용인시 관측치가 아니다.

목적은 읍면동의 인구 구성이 얼마나 비슷한지 분석하는 것이다. 서비스 수요, 개인의 이용 의향, 어르신의 근로 가능 여부를 예측하지 않는다. 정답 라벨이 없으므로 정확도라는 지표를 보고하지 않는다.

## 입력 준비

용인시 [월별 인구통계](https://www.yongin.go.kr/user/bbs/BD_selectBbsList.do?q_bbsCode=1227)의 동일 기준일 인구 및 세대현황과 연령별 인구현황을 사용한다. 현재 확인한 자료는 2026년 10월 말 기준이며 2026년 11월 9일 등록됐다. 원본 확보 후 시트 구조와 이용 조건을 확인해야 한다.

1. 같은 기준일, 같은 주민등록인구 정의 및 같은 행정동 단위로 결합한다. 외국인 포함 총인구와 내국인 연령 분포를 섞지 않는다.
2. 시 및 구 합계와 읍면동 행을 동시에 넣지 않는다. 동명이 있으면 `처인구/중앙동`처럼 구를 포함한 유일한 이름으로 만든다.
3. 원본의 합계와 가공 후 합계를 대조한다. 누락된 연령, 세대 또는 지역을 임의의 0으로 채우지 않는다.
4. 한 지역의 0세부터 14세까지 인구, 65세 이상 인구를 합산한다. 서로 다른 기간 자료를 혼합하지 않는다.

CSV는 UTF-8로 저장하고 아래 열 순서를 사용한다. 인구 수는 쉼표 없는 정수다.

```csv
region,population,households,age_0_14,age_65_plus
```

날짜와 데이터 정의의 일치는 원본 검토 단계에서 확인해야 한다. 스크립트는 원본 파일의 사실 여부나 행정구역 합계 여부까지 자동 판별하지 않는다. 200개 이하의 집계 지역을 지원한다.

## 알고리즘

1. 특성은 아동 비율, 고령 인구 비율 및 세대당 인구다. 비율은 0부터 1까지이고 세대당 인구의 단위는 명이다.
2. 각 특성을 평균 0, 모집단 표준편차 1로 표준화한다. 분산이 없는 열은 0으로 변환한다. 특정 단위의 숫자 크기가 거리 계산을 지배하는 것을 방지한다.
3. K-means++로 초기 중심을 선택한다. 고정 seed 42로 10회 초기화하여 표준화 공간 내 군집 제곱 거리 합(inertia)이 가장 작은 수렴 결과를 선택한다. 빈 군집은 가장 멀리 떨어진 표본을 다른 군집에서 옮겨 복구한다.
4. 최대 300회 반복하며 재할당 결과가 동일해지면 수렴으로 판정한다. 수렴하지 않으면 결과를 발행하지 않는다. 같은 입력의 행 순서가 달라도 지역명 정렬로 결과가 재현된다.
5. 군집 개수는 기본 3이며 사용자가 지정한다. 최적 개수를 알아냈다고 해석하지 않는다. 군집 번호는 중심 좌표로 정렬한 내부 번호이며 순위가 아니다.
6. 군집 내 거리 합과 silhouette(-1부터 1)을 보고한다. 실루엣은 군집 분리도를 설명하며 서비스 성과를 검증하지 않는다. 단일 표본 군집의 실루엣은 0이다.

## 실행 및 결과

```powershell
python experiments/offline_ai/region_clustering.py build/data/yongin-regions.csv build/reports/yongin-clusters.json --reference-date 2026-10-31 --source-url "https://www.yongin.go.kr/user/bbs/BD_selectBbsList.do?q_bbsCode=1227" --data-kind public-aggregate --clusters 3
python -m unittest discover -s experiments/offline_ai -p test_region_clustering.py -v
```

`--data-kind`는 필수다. 합성 입력 검증에는 반드시 `synthetic`을 지정한다. 스크립트는 네트워크 요청을 보내지 않으며 `--source-url`은 출처 기록용이다.

결과 JSON은 입력 CSV SHA-256, 출처 URL, 기준일, 데이터 종류, 특성 평균과 표준편차, 표준화한 군집 중심, 원래 단위의 중심, 지역별 배정 및 평가 지표를 담는다. `predict(model, features)`로 동일한 특성 순서의 새 지역을 가장 가까운 중심에 배정할 수 있다.

모델과 결과는 Python에서 미리 생성하는 작은 파일이며 서버에서 재학습할 필요가 없다. 실제 데이터 결과가 검증되기 전에는 Java 리소스로 포함하거나 운영 화면에 노출하지 않는다. 현재 서버 메모리 및 기존 Gemini, STT, TTS 동작에는 영향이 없다.
