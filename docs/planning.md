# 기획안

## 1. 문제 정의

**한 줄 정의:** 용인의 텃밭은 처인구에 있고 텃밭을 원하는 사람은 수지/기흥에 사는데, 평일 관리를 해줄 사람이 없어서 도시민은 텃밭을 포기하고, 처인구 어르신들은 농사 경험이 있어도 일자리가 없습니다.

### 도시 측 (수지/기흥)

- 주말농장 수요는 있지만 텃밭은 2~3일에 한 번 관리가 필요해, 거리가 먼 직장인은 유지가 어렵습니다.
- 분양 후 방치되거나 시작조차 포기하는 경우가 많고, 꾸준히 관심을 이어갈 동기도 부족합니다.

### 농촌 측 (처인구)

- 전국 기준 농가 경영주 평균연령이 67.7세이고 60대 이상이 78.8%에 달할 만큼 고령화가 심각합니다.
- 어르신들은 농사 경험은 풍부하지만 체력 부담이 적은 소득원이 부족합니다.

### 데이터로 보여줄 그래프

- 용인 주말농장 위치 vs 구별 30~40대 인구 분포 (수요와 공급의 거리 격차)
- 처인구 농가 인구 연령 구조
- 직접 설문: 주말농장을 포기하거나 망설인 이유

### 핵심 사용자

- **도시민:** 수지/기흥의 맞벌이, 아이 있는 가족
- **텃밭 관리사:** 처인구 60대 이상 농업 경험자

## 2. 해결 방안

도시민은 처인구 텃밭 한 칸을 분양받고, 평일 관리는 근처 어르신 "텃밭 관리사"가 시니어 전용 앱으로 AI가 정해준 작업을 수행합니다. 도시민은 앱에서 실제 밭의 날씨대로 자라는 작물 캐릭터를 듀오링고처럼 매일 키우고, 주말에는 직접 방문해 수확합니다. 게임이 평일의 관심을 붙잡고, 어르신이 실제 관리를 책임지며, 처인구는 주말 여가 인프라로 살아납니다.

적용 장소 예시로, 용인농촌테마파크가 3~11월 용인시민에게 가족당 3~5평 밭을 주말농장으로 분양하고 있습니다.

## 3. 핵심 기능

### 3.1 AI 오늘의 작업 생성 (AI 핵심 1)

기상청 예보, 작물별 재배 정보, 지난 작업 기록, 어르신의 음성 메모를 종합해 텃밭마다 오늘 필요한 작업만 골라냅니다. "내일 비 예보, 물 주기 생략"처럼 불필요한 작업은 빼서 관리사의 부담과 비용을 줄입니다.

### 3.2 AI 성장 시뮬레이션 (AI 핵심 2)

처인구 실제 날씨 데이터(누적 기온, 강수, 일조)와 농진청 작물별 생육 기준으로 AI가 작물의 현재 성장 단계와 수확 예정일을 예측합니다. 이 예측이 게임 속 작물 캐릭터를 움직이는 엔진입니다.

현실적인 보정 방법이 필요하면, 어르신 앱에 "꽃 폈어요", "열매 맺혔어요" 같은 단계 확인 버튼을 하나 두는 정도가 적당합니다. 버튼을 누르면 게임 속 단계가 실제와 맞춰집니다. (선택 사항)

### 3.3 AI 텃밭 퀴즈 (선택 기능)

핵심 기능에서 빼고 부가 기능으로 내립니다. 시간이 남으면 넣고, 발표에서는 "확장 기능" 정도로만 언급합니다.

### 3.4 듀오링고식 게임 화면 (도시민)

- **작물 캐릭터:** 표정 있는 캐릭터가 씨앗, 새싹, 꽃, 열매 단계마다 진화 애니메이션을 보여줍니다. 비 오는 날엔 우산을 쓰고, 더운 날엔 땀을 흘리는 등 실제 날씨에 반응합니다.
- **스트릭:** 매일 들어와 퀴즈를 풀거나 응원하면 불꽃이 쌓이고, 끊기면 캐릭터가 시무룩해집니다.
- **XP와 리그:** 같은 농장 이웃 텃밭끼리 주간 XP 순위 경쟁
- **주간 퀘스트:** "할머니에게 감사 하트 보내기", "퀴즈 5개 풀기" 달성 시 배지와 보상 애니메이션
- **수확 이벤트:** 수확 예정일에 큰 축하 애니메이션과 주말 방문 예약 버튼

### 3.5 관리사 화면 (수정)

하나의 앱에서 가입 시 **"텃밭 주인"**과 **"텃밭 관리사"** 중 역할을 고르면, 역할에 따라 홈 화면이 달라집니다.

- **텃밭 주인 모드:** 작물 캐릭터, 스트릭, 리그 등 듀오링고식 게임 화면
- **관리사 모드:** 오늘 할 텃밭 카드만 크게 보이는 단순 화면, 버튼은 "완료"와 "말로 남기기" 두 개, 음성 안내, 완료 시 꽃 피는 애니메이션

### 3.6 어르신 아바타

가입 시 셀카 한 장을 찍으면 AI가 일러스트 아바타로 변환합니다. 도시민 화면에서 "순자 할머니가 물을 주셨어요" 같은 메시지와 함께 등장해, 누가 내 텃밭을 돌보는지 얼굴로 느낄 수 있습니다. 초상권 동의 절차를 거치고, 원하지 않으면 기본 캐릭터를 씁니다.

### 3.7 주말 나들이 연결

수확일에 맞춰 근처 체험농장과 로컬 식당을 함께 추천해 처인구 여가 코스로 확장합니다.

## 4. 활용 데이터

| 데이터 | 출처 | 용도 |
|---|---|---|
| 주말농장 현황 | 공공데이터포털 | 명칭, 위치, 구좌 수, 연락처 (공급 지도와 매칭) |
| 농림어업총조사 | KOSIS | 용인시 농가 인구와 연령 |
| 주민등록 인구 (구별, 연령별) | 미기재 | 수지/기흥 수요층 분석 |
| 단기예보 및 과거 관측 데이터 | 기상청 | 작업 생성과 성장 시뮬레이션 |
| 농사로 API | 농촌진흥청 | 작물별 생육 단계, 재배 일정, 퀴즈 소재 |

## 5. 기술 구성

- **작업 생성:** LLM과 규칙 기반 검증 (엉뚱한 지시 방지)
- **성장 시뮬레이션:** 작물별 필요 누적 기온 기준에 날씨 데이터를 적용한 예측, LLM이 결과를 쉬운 말로 설명
- **퀴즈 생성:** 선택 기능으로 이동
- **음성 메모:** STT 후 LLM으로 이상 징후 추출
- **아바타:** 이미지 생성 API로 일러스트 변환 후 저장
- **애니메이션:** Rive 또는 Lottie로 캐릭터 상태(날씨, 성장 단계, 기분)별 애니메이션 구현

## 6. 운영 구조 (사업성 질문 대비)

- 도시민 월 이용료 (가정: 월 3만 원) 중 일부를 관리사 수당으로 지급
- 어르신 1명이 한 농장에서 텃밭 15~20칸을 맡아 하루 1~2시간 작업
- 용인시 노인일자리 사업과 연계해 수당 일부를 공공 재원으로 보전 가능

> 숫자는 발표에서 "가정"이라고 명시할 것.

## 7. 차별점 (Q&A 대비)

- **기존 앱과의 차이:** 주말농장 분양과 농장주에게 물주기, 사진 요청을 할 수 있는 '첫밭' 같은 서비스가 있지만, 도시민이 직접 요청해야 하고 재미 요소가 없습니다. 우리는 AI가 작업을 판단하고, 게임으로 매일의 관심을 이어갑니다.
- **어르신 일자리:** 관리 주체가 지역 어르신이라 일자리 창출 효과가 있습니다.
- **"어르신이 앱을 쓸 수 있나요?":** 버튼 두 개짜리 시니어 전용 화면이고 음성 안내가 있다고 답합니다. 실제 어르신 1~2분께 시제품을 보여드린 영상이나 반응을 넣으면 가장 강력합니다.
- **"게임 속 성장이 실제와 같나요?":** 실제 처인구 날씨와 농진청 생육 기준으로 계산한다고 답합니다. 단계 확인 버튼을 넣었다면 "관리사가 실제 단계를 확인해 맞춘다"고 덧붙입니다.

## 8. 시연 시나리오 (2분)

1. 도시민 화면: 텃밭 추천, 방울토마토 선택, 씨앗 캐릭터 등장 애니메이션, 담당 할머니 아바타 소개
2. 날씨를 비로 바꾸면 캐릭터가 우산을 쓰고, AI가 "오늘 물 주기 생략" 작업을 생성
3. 어르신 앱으로 전환: 큰 작업 카드, 음성 안내, 완료 버튼, 꽃 피는 애니메이션
4. 도시민 화면: "순자 할머니가 돌봐주셨어요" 메시지, AI 퀴즈 풀기, 스트릭 불꽃 증가
5. 시간을 빨리 감아 열매 단계 진화 애니메이션, 수확 축하 이벤트와 주말 방문 예약으로 마무리
